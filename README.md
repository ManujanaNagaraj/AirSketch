# AirSketch

Draw in thin air using just your hand

## Features

- Real-time hand tracking
- Gesture-based drawing
- Erase with pinch
- Color switching
- Clear canvas

## Installation

pip install -r requirements.txt

## How to Run

python main.py

## Gesture Controls

| Gesture | Action |
|---|---|
| Index finger up | Draw |
| Fist | Pause |
| Pinch | Erase |
| 2 fingers | Red |
| 3 fingers | Green |
| 4 fingers | Blue |

## Requirements

- Python 3.8+
- Webcam
